# Sistema de Eventos Universitários
LINK: https://estevanrodrigues.github.io/sistemas-de-eventos-universitarios-/
Projeto front-end desenvolvido para uma universidade, com o objetivo de divulgar e organizar eventos acadêmicos, como palestras, minicursos, workshops e oficinas.

O projeto foi desenvolvido utilizando **HTML5 e CSS3**, aplicando conceitos de **HTML semântico, organização de layouts, tabelas, formulários, navegação entre páginas e design responsivo**.

### Tecnologias utilizadas

* HTML5
* CSS3
* Design Responsivo

### Objetivo

Desenvolver uma interface moderna, organizada e responsiva para facilitar a divulgação dos eventos universitários e permitir que os usuários consultem a programação e realizem inscrições.

### Estrutura do projeto

* Página inicial
* Sobre a universidade
* Programação dos eventos
* Página de inscrição
* Informações dos eventos
* Layout responsivo para diferentes dispositivos
